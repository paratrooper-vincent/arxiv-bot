# arXiv 新论文推送机器人（数据飞轮小 Demo）

每天自动抓 arXiv 最新论文 → 按关键词筛选 → 推送到飞书群。

## 文件说明

| 文件 | 作用 |
|---|---|
| `arxiv_bot.py` | 主程序，跑它就行 |
| `config.json` | 配置：关键词、飞书机器人地址等，改这里不用动代码 |
| `seen.json` | 自动生成。记住哪些论文已经推过（状态持久化） |
| `run.log` | 自动生成。每次运行的记录，出问题时看它 |
| `run_bot.bat` | 双击即可运行一次主程序 |

## config.json 各项含义

- `categories`：抓哪些栏目，`cs.RO` = 机器人学。想加别的栏目照格式加，如 `"eess.SY"`
- `keywords`：标题或摘要里出现任意一个词就选中（不分大小写）
- `fetch_count`：每次抓最新多少篇来筛
- `max_push`：一次最多推几篇，防止刷屏
- `feishu_webhook`：飞书机器人的网址。**留空 = 预览模式**（只打印不推送）

## 日常使用

- 手动跑一次：双击 `run_bot.bat`
- 测试/预览：把 `feishu_webhook` 清空再跑，消息只打印在屏幕上，不会记录"已推"

## 已实现的核心练习点

1. 工具调用：请求 arXiv 官方接口 + 飞书机器人接口
2. 错误重试：失败自动重试 3 次，间隔递增（见 `retry` 函数）
3. 状态持久化：`seen.json` 防止重复推送；`run.log` 留痕
